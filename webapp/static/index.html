                💡 公众号配置温馨提示（需要你手动操作）
                

                  
1. 只有已认证的公众号才能用 API 推草稿；个人订阅号不支持，只能手动发布。

                  
2. 登录公众号后台：mp.weixin.qq.com → 设置与开发 → 基本配置。

                  
3. 开发者ID(AppID) 直接复制；开发者密码(AppSecret) 需点「重置」后才会完整显示一次，务必当场保存。

                  
4. 同一页面把「IP白名单」改成你电脑的公网 IP（浏览器搜索"我的IP"即可查到），保存后 1-5 分钟生效。

                  
5. 平台无法代替你完成以上操作；配好后保存，再到成品库点「推送到公众号草稿箱」。

                  
6. 详细图文步骤见「发布指引」（成品库页）。
