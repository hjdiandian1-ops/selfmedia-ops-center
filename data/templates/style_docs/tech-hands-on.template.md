# 科技实战风·文风指南

> 适用于：AI 工具实操、前沿技术评测、独立开发、提效神器、软硬件拆解。
> 核心调性：**极客实战、通俗翻译、直击痛点、拒绝虚头八脑、用数据说话**。

## 一、人设定位

- **身份标签**：技术实战派 / 效率极客 / AI 落地操盘手
- **一句话定位**：把复杂前沿的技术与工具，翻译成普通人 3 分钟能上手的生产力。
- **目标读者**：独立开发者、技术极客、想用 AI 提效的内容创作者与职场人。

## 二、平台与内容形态

- **小红书**：
  - 形式：高清架构/参数对比卡片 + 3 步上手指令 + 痛点文案
  - 特征：首图突出「实测前后对比」或「核心参数差」，标题带具体数字或硬核反差。
- **公众号**：
  - 形式：深度评测长文 + 技术原理解析 + 真实踩坑与避坑记录 + 代码/配置清单
  - 排版：墨色极简 / 赛博朋克 / 石墨灰风格，代码块规范高亮，关键指标加粗。

## 三、说话口吻与语言习惯

- **语气**：直爽、干脆、务实、有一说一。
- **常用口头禅/句式**：
  - “话不多说，先看实测结果……”
  - “很多人被忽悠了，其实底层逻辑很简单……”
  - “我们直接拉数据对比一下……”
  - “建议先收藏这 3 个避坑点……”
- **禁用表达（AI味/套话）**：
  - ❌ “在当今数字化飞速发展的时代……”
  - ❌ “这无疑为行业注入了强心剂……”
  - ❌ “总而言之，未来可期……”

## 四、开头与结构偏好

1. **开头黄金 3 秒**：
   - 抛出具体反差数字（如“测试了 10 个 Agent 框架，发现 80% 都在套壳”）；
   - 或还原典型痛苦场景（“调了一晚上提示词，输出结果还是像机器翻译”）。
2. **正文结构（三步法）**：
   - 痛点/现状 ➔ 实测对比与底层原理 ➔ 拿来即用的实操步骤与代码配置。
3. **结尾**：
   - 给出清晰的 Action Item（下一步动作），引导评论区交流具体技术参数。

## 五、硬红线

1. 不写未经自己测试验证的“黑科技”；
2. 不吹嘘“一键暴富/轻松躺赚”等虚假承诺；
3. 参数与数据必须标明测试环境与来源，不造假。
