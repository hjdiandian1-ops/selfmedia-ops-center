03机制解剖：为什么扎堆开源，钱归谁

先说为什么是现在。三个机制叠在一起。

第一，后训练 Scaling 把迭代周期压短了。GLM-5.3 基座不变，靠数十倍规模的长程任务环境做后训练，把 Terminal-Bench 3.0 从 4.6 拉到 28.3；DeepSeek V4-Pro 从预览到正式版，DeepSWE 从 12.8 涨到 62.7。能力提升不再必须重新预训练，开源节奏自然变成月更、周更。

第二，权重开源是生态入口。模型边际分发成本趋零之后，厂商的账本转向 API、工具链、云算力和企业服务。DeepSeek Harness 开源当晚就有人讨论它和调价的关系，工具免费拉开发者进来，算力按峰值价格卖出去。

第三，开源本身是信任广告。权重、技术报告、训练基础设施一起公开（Kimi K3 附带 MoonEP），开发者社区成为分销渠道，人才池也在这里。

钱归谁？三层。算力层拿电费和 GPU 租金；工具层拿推理引擎、agent 框架和托管费；数据与流程层拿你工作流里沉淀的判断。模型本身越来越像水电，中间商越来越难收租。我自己选型时只记四列：权重能不能下、协议能不能商用、本地要几张卡、API 每百万 token 多少钱。这四列写完，广告词基本失效。

04稀缺品论证：模型趋零，什么变贵

沿这条线推下去：权重和推理成本趋零，供给无限，注意力、信任和流程定义权变贵。三个稀缺项正在被重新定价。

一是能把长任务拆成回合并验收的人。同样的模型，有人 53 回合跑完，有人绕 103 回合，差别在提示词设计、工具编排和验收标准。

二是能读懂许可条款和供应链风险的人。MIT 最省心，Qwen 和 Llama 各有自定义条款，商用前要把能否商用、数据能否回流、模型卡是否合规读一遍。

三是能在自己数据上做后训练的人。公开权重给的是起点，真正拉开差距的是用私有数据继续训练的能力。

05行动判断：三条，照着抄

第一条，按场景选模型。编程和终端操作优先 GLM-5.3（权重 8 月底开放，先用官方渠道）或 DeepSeek V4-Pro；长文档与多模态 agent 选 Kimi K3；办公、科研与长程任务选 Qwen3.8-Max。

第二条，商用前先读许可条款。DeepSeek 走 MIT 最省心；Qwen3.8-2.4T-A95B 与 Llama 5 是自定义协议，别拿开源两个字替律师做决定。

第三条，把总成本写进选型表。权重 0 元不等于推理 0 元；API 涨价之后，自部署、量化托管和按需 API 三份报价单要一起比。

∞写在最后

模型会继续免费，跑分也会继续过期，能把权重变成产出的人会越来越值钱。模型免费，判断值钱。
