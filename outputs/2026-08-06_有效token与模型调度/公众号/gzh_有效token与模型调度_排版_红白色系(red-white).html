DeepSeek 今天涨价了，但你真正该慌的不是价格—— 是你的有效 token 一直在漏 。

—— 小吴聊

DeepSeek 8 月 6 日官宣整体上调 API 定价，预计涨幅较大。这不是孤例——2026 年以来，智谱、月之暗面、MiniMax、阿里云、腾讯云、百度智能云已经集体调过价。

半年前我写过一句话： 真正决定你 AI 账单的，不是模型单价，而是你的"有效 token" 。当时没人接话。今天涨价一来，这句话突然被行业用真金白银认同了。

我自己的内容工厂就跑在 NAS 上，每天几个档期无人值守调模型，所以对"token 怎么烧钱"比谁都敏感。这篇文章不聊情绪，只拆三件事： 价怎么涨的、为什么"有效 token"成了硬指标、谁在帮企业把这块成本压下去 。

01

PRICING

一个数字看懂为什么涨

DeepSeek 的计费结构里有两个数字，才是真正的关键：

缓存命中价

0.02

元 / 百万 Token

缓存未命中价

1.00

元 / 百万 Token

中间差 50 倍 。而且高峰时段（工作日 9–12、14–18 点）价格还会再翻倍。

算力供不应求，涨价是产能跟不上的信号。但更值得盯的不是涨价本身，而是 这个价差结构 ——它把"会不会用"和"会不会浪费"直接标了价。

02

CONCEPT

我提的"有效 token"，今天被行业认同了

概念很简单：真正产生价值的 token，叫"有效 token"；每轮都把全量上下文重新发一遍、被浪费掉的，叫"无效 token"。

DeepSeek 的计费结构就是它的注脚： 缓存命中率 90% 的用户，输入侧实际单价仅为零命中用户的 1/8 。涨价真正打中的，是那些"全量重发、按未命中价全额承受"的用户。

更妙的是，行业里已经有人把"有效 Token"写进技术路线了。无问芯穹的公开表述是：

"在同等硬件损耗下榨取并交付远超均值的有效 Token 数量。"

这不是我发明的词，是厂商自己在用的产品语言。从"卖模型"到"卖有效 Token"，已经是赛道共识。

03

PLAYERS

谁在帮企业省下有效 token

把成本压下来的能力，拆开看是五项：

① 模型路由：把对的问题发给对的模型，不滥用贵模型。

② 推理加速：同样硬件榨出更多有效 Token。

③ 缓存复用：前缀固化，命中率拉满。

④ 数据治理：干净上下文，少喂垃圾 token。

⑤ 成本控制：峰谷调度、批处理、量化。

旁证（沙利文白皮书）：某大型国有商业银行通过统一 AI 基础设施平台，GPU 资源效率提升 70%+、AI 部署效率提升 60%+。这个赛道正在资本化——硅基流动、基流科技递表港交所，无问芯穹、趋境科技接连大额融资。从"卖模型"到"卖 Token"，已经不是概念，是财报和招股书里的数字。

我的判断

API 价格进入上行周期，企业注意力会从"哪个模型最强"转向"单位调用成本最低"。拥有模型路由、推理加速、数据治理、成本控制能力的软件企业，价值可能被重估。

但这是产业观察，不是投资建议。融资和递表只是信号，不代表商业兑现；模型降价周期也可能回摆。看赛道逻辑，别看单日涨跌。

最后一句话： DeepSeek 涨价的新闻，真正有用的不是"贵了"，而是它把"有效 token"这件事，从个人经验变成了行业账本。
