给每个不想加班的打工人：AI 同事来了

8月11日，xAI 放出 Grok Bot 早期测试版——不是又一个聊天机器人，是「云端 AI 同事」：能登录你常用的工具和网站，把活从头干到尾，你合上电脑它也继续干。

4 个数字，先看懂它👇

1️⃣ 每席每月 120 美元（约合 840 元）
团队版 Cursor Premium Teams 每席位每月 120 美元；个人版 Cursor Ultra 200 美元/月（约 1400 元）；SuperGrok Heavy 用户 300 美元/月（约 2100 元）。已订用户不用再掏钱，超出套餐额度按 token 计费。

2️⃣ 600 亿美元的「同事工厂」
6 月 SpaceX 以 600 亿美元收购 Cursor，Grok Bot 就挂在 Cursor 订阅体系里。每个 Bot 有一台独立云端电脑，能看、能点、能打字；没有 API 的旧软件，它也照用。

3️⃣ 24 小时在线，演示一次就学会
示范一遍完整操作，它存成 routine 下次自己跑；多个 Bot 能互传上下文、群聊分工，一个干完交给下一个。内部已经用它跑销售、招人、报销和修 bug。

4️⃣ 同周，Grok 4.6 发布
API 定价每百万输入 token 2 美元、每百万输出 token 6 美元，主打长时运行的 agent 任务——模型和同事一起到位。

一句提醒（目前最大的安全与权限争议）：多个 Bot 共用登录状态，权限按用户分；支付、敏感操作会弹 Auto-review 卡要你确认。用之前先想清楚，哪些账号敢交给它。
