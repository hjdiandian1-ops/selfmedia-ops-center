# 120s 黄金分镜脚本：停更一周，我搭了台自己跑内容的工作台

## 0-3s Hook（话题 + Hook + 可信度）

- 画面：快速推镜到工作台概览页，鼠标划过「曝光 1123 → 观看 570」漏斗图
- 运镜：手持感快推，画面轻微晃动
- 台词：停更一周，我搭了台每天自己跑内容的工作台。
- 花字：停更一周＝换产能（红色大字）
- 音效：键盘敲击 + 低音鼓点
- 素材绑定：M1、M3

## 3-15s 切入

- 画面：切到选题页，鼠标点开日选题列表，8 条带评分
- 运镜：固定机位 + 屏幕录制内滚
- 台词：这一周没怎么发文，不是在偷懒。现在 8 条日选题、10 条周选题，每天机器帮我排好，我只要拍板。
- 花字：8 条日选题 / 10 条周选题
- 音效：清脆提示音
- 素材绑定：M4

## 15-60s 硬核拆解（选题 → 生产 → 质检）

- 画面：依次切流水线状态机、成品库质检报告
- 运镜：逐屏平移，节奏跟着台词走
- 台词：点一下【采纳生产】，小红书、小绿信、视频脚本自动开跑。选题、素材、成稿、视觉、质检、归档、发布、回收，8 态状态机一条龙。质检不是走过场，契约校验 PASSED、Harsh Critic 98/100 才算归档。
- 花字：8 态状态机 / 98/100
- 音效：流水线传送带声 + 每过一态一声「叮」
- 素材绑定：M7、M8

## 60-90s 避坑反转

- 画面：切到数据飞轮页，手指划过「写稿发布 → 账户反馈 → 市场学习 → 总结经验 → 反哺 Agent」
- 运镜：跟随箭头横移
- 台词：很多人问我跟 workbuddy 一键导入生成的模板差在哪。差在数据飞轮：25 次发布动作、33 条回填、2.5 万阅读、2.2% 互动率，全部压成 6 条经验，再写回 Agent 的 SOP。模板是死的，这条轮子是活的。
- 花字：25 / 33 / 2.5万 / 2.2% / 6 条经验
- 音效：数据流动音效，最后一声齿轮咬合
- 素材绑定：M3、M6

## 90-120s 升华金句

- 画面：切回概览页，停留 2 秒后黑场，浮现一句话
- 运镜：缓慢拉远
- 台词：工具可以一键生成，系统不能。这周停更，是为了以后不再断更。
- 花字：工具可以一键生成，系统不能
- 音效：音乐收束，留一声呼吸感
- 素材绑定：M1、M2
