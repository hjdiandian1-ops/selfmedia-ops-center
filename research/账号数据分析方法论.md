# 账号数据分析方法论（概览看板诊断依据）

> 概览看板的「薄弱点诊断 / 健康度 / 本周最重要的一件事」由规则引擎按以下方法论产出，保证可复现、可解释。

## 1. 漏斗分析（AAARRR 变体）

把每个平台拆成「曝光 → 触达 → 互动 → 转化」的转化链路，找“漏点”在哪一层：

- 小红书：曝光 → 观看 → 点击率 → 互动（赞/藏/评）→ 收藏 → 涨粉 → 完播
- 公众号：群发触达 → 打开 → 阅读完成 → 转发/在看 → 关注
- 短视频：播放 → 前 3 秒留存 → 完播 → 互动（赞/评/藏）→ 关注

诊断动作：哪一层转化率低于基准，就先优化哪一层（如点击率低 → 封面/标题；互动低 → 正文钩子；涨粉低 → 关注引导）。

## 2. 内容支柱分析

把内容按主题/体裁/标题风格分桶，比较各桶的平均阅读与互动率：

- 找出“稳定出量”的支柱主题 → 加大投入；
- 找出“阅读高但互动低”的主题 → 只补互动钩子；
- 找出“全维度低”的主题 → 从选题阶段淘汰。

数据来源：`data/stats` 的笔记明细 / 主题聚合（`/api/stats` 的 by_theme / content_insights）。

## 3. 基准对比（行业/自身双基准）

- 行业基准：平台均值或本工作台内置阈值（如点击率 ≥10%、互动率 ≥1%、涨粉率 ≥0.1%）；
- 自身基准：上一周期（近 7 日 vs 前 7 日）环比，看趋势而不只看绝对值。

健康度 = 各可算指标相对基准的归一化加权分（0-100），缺失指标不计权并在雷达图置灰。

## 4. 环比诊断

当某指标环比下降超过阈值（如互动率 -20%），优先复盘：选题来源、标题公式、发布时间、体裁结构最近一周的变化，回到已验证的爆款公式。

## 落地方式

- 规则阈值集中在 `scripts/dashboard_analysis.py` 顶部常量；
- 每条诊断输出：现状 → 基准 → 原因 → 行动建议 → 适用 Agent；
- 一键「沉淀为经验」写入数据飞轮，自动升级对应 Agent SOP。
