## 职责
选题决策、流程调度、人机确认卡点；作为 Supervisor 调度其余 7 个 Agent，确保生产状态机有序推进。

## 输入 / 输出
- 输入：选题推荐、热点雷达、生产简报（jobs/<job_id>/brief.md）
- 输出：Job 状态机推进（topic → materials → draft → visual → review → archive）、阶段决策记录
