# 封面设计 Skill（Cover Design）

将外部 oh-my-cover-design 的「8 问引导流程 + 10 种构图风格」熔炼进小吴聊内容体系：默认红白品牌色、双平台规格硬门、数据可视化与 AI 封面分工、真人出镜安全边界。

## 使用边界

用本 skill：AI 生成的封面/配图——小红书 3:4 封面、公众号 21:9+1:1 封面、公众号正文宽幅插图、配图生图提示词。

不用本 skill：HTML 数据卡片（走 `guizang-social-card-skill`）、公众号排版（走 `gzh-design-skill`）、文中图表（走 `generate_data_viz.py`）。

## 铁律（违反即返工）

1. **真人出镜必须有用户提供的人脸参考图（图1）**。没有参考图时禁止编造真人脸；改走背影风 / 局部出镜风 / 产品主视觉风 / 纯字封面。用户明确要求"虚拟形象"除外，但需在交付说明中标注。
2. **AI 图内禁止出现假数据、假表格、假链接、假统计**。数字对比一律用 HTML 数据卡片；图内文字只放封面标题（4-8 字），公众号 21:9 可加一行副标题。
3. **默认红白品牌色**（主红 `#DC2626`，底色白/米白/深红黑渐变）；只有用户明确选择其他色调才偏离。
4. **禁止发光/全息/粒子/数据流等特效**（廉价感）；提示词只写正面描述（画面里有什么），不写否定句。
5. **提示词必须可执行**：人物姿势、手部动作、元素位置/大小/遮挡关系写具体，禁止"她做了一个动作"这类模糊描述。
6. **每张图交付前必须过规格检查 + 人工目检**。

## 工作流

### 1. 输入确认

- 文章/主题、目标平台（小红书封面 / 公众号封面 / 正文插图）。
- 已有标题与核心视觉元素（如 NAS、n8n、芯片、技能卡片）。
- 是否有可用的真人照片、UI 截图、产品图。

### 2. 八问（一次只问一个，等回答再问下一个）

风格模板详见 [references/style-templates.md](references/style-templates.md)，问答顺序：

1. **选风格**：10 选 1（深色渐变 / 纯色扁平 / 产品主视觉 / 对比卡片 / 极简留白 / 海报拼贴 / 人物侧置留白 / 背影 / 局部出镜 / 正面对视）。
2. **图1 人脸参考**：有 → 让用户上传；没有 → 按铁律 1 收敛到无脸风格。
3. **人物表情**（背影风跳过）：捂嘴惊讶 / 张嘴震惊 / 开心大笑 / 兴奋雀跃 / 自信得意 / 托腮思考 / 推荐种草感 / 交给模型决定。
4. **额外素材**：图2/图3（UI 截图、产品图、其他参考）有几张、各是什么。
5. **背景色调**：默认红白系；极简留白风与人物侧置留白风默认浅色，此问可跳过。
6. **字体风格**：默认超粗黑体（干货/科技）或极简无衬线（公众号大气）；手写体/复古宋体仅在用户点名时使用。
7. **字体颜色效果**：深底白字 / 浅底红字（品牌默认）/ 渐变 / 描边。
8. **封面标题**：基于文章提炼 1-3 个 4-8 字候选，用户确认或修改。

如果用户已给出足够信息，可一次走完并列出确认清单，但每项必须显式可追溯。

### 3. 生成提示词

- 打开 [references/style-templates.md](references/style-templates.md)，按所选风格模板填槽。
- 参考图在提示词里只写"图1/图2"，不复述图中细节。
- 中文封面标题用引号包裹（如：巨大的中文大字"降本增效"）。
- 主视觉元素描述必须包含：外观/内容/大小比例/动态或静态/与人物前后遮挡关系。

### 4. 生成与合成

- **无参考图需求**：直接调用 `scripts/generate_ai_image.py --prompt "..." --ratio 3:4 --output outputs/<job_id>/小红书/ai_cover.png`（公众号 21:9 / 1:1 同理）。
- **有参考图需求**：当前 SiliconFlow 文本生图连接器不支持图1/图2 参考图。走以下任一路径：
  - 即梦 / 可灵网页端手动上传参考图并粘贴提示词；
  - 本地用参考图 + 生成结果做合成（人脸用用户照片，背景/文字用生成图）；
  - 或改用不需要参考图的无脸风格。
- 生成后按 [references/qa-checklist.md](references/qa-checklist.md) 逐项核对。

### 5. 检查与交付

- 运行 `python3 skills/cover-design-skill/scripts/check_cover_specs.py <图片路径或目录>`，规格 FAIL 必须修复后重出。
- 人工目检：3 秒可懂、标题无遮挡、元素不出安全区、无大空白带、无廉价光效。
- 交付：图片路径 + 使用的风格/提示词 + 规格检查结果；参考图路径与合成方式如实说明。

## 与现有体系的衔接

- 小红书 3:4 封面：AI 封面为封面页（可选），数据页仍用 `guizang-social-card-skill` HTML 卡片。
- 公众号封面：AI 出图后按 21:9 + 1:1 成对交付，禁止一张图盲裁两版。
- 正文插图：宽幅 ≥1.6:1，竖图用 `sips` 中心裁切；流程/结构图用 HTML 画布渲染，不用 AI 生图。
- 所有图片 PNG 不入 Git（`.gitignore` 已拦截）；只提交提示词/JSON/HTML/MD。
