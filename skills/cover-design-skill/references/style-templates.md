# 封面构图风格模板（10 种）

> 默认红白品牌系：主红 `#DC2626`；底色白/米白/浅灰，或深红黑渐变。用户另选色调时整体替换描述。
> 图内中文标题一律用引号包裹；禁止在 AI 图内放数字、表格、链接、长句。
> 参考图：图1=人脸（仅用户提供），图2+=UI/产品截图。

## 风格一：深色渐变风

人物居中，大字覆盖人物后方，深色渐变背景，高对比强冲击。

- 背景：深红黑/墨黑渐变（柔和过渡），高饱和。
- 字体：超粗黑体，白色或渐变，覆盖在人物身后，被人物部分遮挡。
- 前景：少量扁平图标或 3D 拼贴小物件点缀。
- 人物：参考图1 五官，只要半身；元素不超出安全区。

提示词模板：

```text
参考图1的[性别]五官特征，保持五官一致性，只要半身。
[具体表情描述]，[人物身体位置和姿势]，[右手/左手的具体动作]，
[主视觉元素的叙事行为，描述清楚人物和元素之间发生了什么]，
[主视觉元素的详细描述：形状/内容/大小/动态]，
（如有图2/图3：[参考图编号]作为[具体呈现方式和位置]）
巨大的中文大字"[封面标题]"覆盖在人物背后，[字体风格]，[颜色效果]，被人物和主体部分遮挡，形成视觉层次感
背景：深红黑渐变，柔和过渡
所有元素集中在中间区域，上下留边距，不超出安全区
前景散点分布几个极小的[主题相关小元素]，数量极少，只做点缀，部分遮挡文字边缘
悬浮元素轻微投影，高饱和度，又整齐又凌乱的美感
```

## 风格二：纯色扁平风

人物抠图感，纯色背景，干净清爽。

- 背景：白/米白纯色（品牌默认），不要渐变；主体高饱和、背景低饱和。
- 字体：超粗黑体，正红或深灰，被主体部分遮挡形成层次。
- 人物：参考图1 五官，只要半身。
- 前景：少量扁平图标，轻微投影。

提示词模板：

```text
参考图1的[性别]五官特征，保持五官一致性，只要半身。
[具体表情]，[人物身体姿势]，[手的动作：推出/举起/展示]，
[主体道具]占据画面大面积，带明显动态模糊，强烈近大远小透视感，
[主体道具的详细描述：外观/内容/材质]，
（如有图2：[道具/界面]显示参考图2内容，极简干净）
背景：[白/米白纯色]，简单纯色扁平，不要任何渐变
画面[上方/中央]超大中文"[封面标题]"，[字体风格]，[颜色效果]，字体被主体部分遮挡，形成视觉层次感
前景散点几个极小的[主题相关图标]，轻微投影，部分遮挡文字边缘
主体高饱和度，背景低饱和，对比清晰
```

## 风格三：产品主视觉风

UI 截图或产品图占画面主体，人物偏小做引导。**图2 必须提供**（产品图/截图），没有就不选此风格。

- 产品/截图：占画面 60-70%，白底清晰、细节可读。
- 人物：偏小（约 25%），在产品旁做引导手势或眼神指向。
- 背景：浅色/中性色；字体压在产品边缘（深色或白色）。
- 人物：参考图1，体量偏小，做引导姿态。

提示词模板：

```text
参考图1的[性别]五官特征，保持五官一致性，只要半身，人物体量偏小。
人物置于画面[左/右]侧偏下，占比约25%，[具体引导手势：右手伸出指向/侧身朝向等]，
[具体表情]，眼神朝向主视觉方向，
参考图2作为画面主视觉，占据画面约65%，[具体呈现方式：悬浮在空中/人物身旁展开/充满背景等]，
[图2内容的具体描述：界面的哪些部分清晰可见，白底还是深色底，内容如何排列]，
（如有图3：参考图3作为[具体位置和呈现方式]）
"[封面标题]"，[字体风格]，[颜色效果]，压在产品[顶部/一侧]边缘，形成层次感
背景：[浅色/中性色调，让产品成为主角]
所有元素集中在中间区域，不超出安全区，轻微投影，视觉层次感
```

## 风格四：对比卡片风

人物手持两张对比卡片，前景大后景小推向镜头，适合前后对比、好坏对比内容。

- 前景卡片：大、亮、占画面主体，带动态模糊；卡片上只写短短语（如"旧方法/新方法"），禁止放数字。
- 后景卡片：小、暗、偏远景，透视缩小。
- 人物：居中，双手分持两卡，表情强烈；背景深色渐变。
- 人物：参考图1，居中，只要半身。

提示词模板：

```text
参考图1的[性别]五官特征，保持五官一致性，只要半身。
[具体表情，要有强烈对比感：得意/震惊/推荐感]，人物居中，
左手捏着一张[小/暗淡/破旧感]的卡片，偏远景，
卡片上写着"[卡片B内容，代表before/坏的一面]"，[卡片B视觉描述]，
右手将一张[大/明亮/发光]的卡片猛地推向镜头前方，
卡片上写着"[卡片A内容，代表after/好的一面]"，[卡片A视觉描述]，
前景卡片占画面大面积，带明显动态模糊，强烈近大远小透视感，
两张卡片[具体对比关系描述]，对比强烈，
巨大的中文大字"[封面标题]"覆盖在人物背后，[字体风格]，[颜色效果]，形成视觉层次感
背景：[深色系，衬托卡片对比]
所有元素集中在中间区域，不超出安全区
悬浮元素轻微投影，前景小元素部分遮挡文字边缘
```

## 风格五：极简留白风

大面积留白，文字是主视觉锤，人物轻量出镜。

- 背景：白/米白/浅灰，留白 >60%。
- 人物：体量小（20-25%），偏角落；表情轻量，不过度夸张。
- 字体：偏细或中等黑体，深红/深灰，字间距宽松，是唯一视觉锤。
- 人物：参考图1，体量小，偏一侧或下方。

提示词模板：

```text
参考图1的[性别]五官特征，保持五官一致性，半身，体量偏小。
人物置于画面[左下/右下/一侧]，占比约20%，[简单姿势]，
[轻量表情，不要过度夸张]，眼神/身体朝向留白区，
画面[对侧/上方]大面积[白色/米白/浅灰]留白，
超大中文"[封面标题]"占据留白区主体，[字体风格，偏细或中等粗细]，[深红/深灰]，
字间距宽松，呼吸感强，
[如有副标题：一行小字灰色，作为补充信息]
背景：整体[浅色色调]，极简，无装饰
构图克制，留白是设计的一部分，不超出安全区
```

## 风格六：海报拼贴风

多张参考图分层叠加，前中后景明确，叙事丰富纵深感强。建议至少提供一张额外素材（图2）。

- 前景：最大素材图或人物，带景深/投影。
- 中景：人物或次要素材，与前景有遮挡。
- 后景：模糊背景素材，丰富但不抢主视觉。
- 字体：压在层次之间，白色或描边效果；背景深色。
- 人物：参考图1。

提示词模板：

```text
参考图1的[性别]五官特征，保持五官一致性，只要半身。
[具体表情]，[人物姿势和身体位置]，
前景：[前景元素详细描述，大小、位置、视觉细节]，占画面约[比例]，带轻微投影和浮动感，
中景：人物主体，与前景元素有遮挡关系，[人物被前景遮挡哪个部位]，
后景：[后景元素描述，轻微模糊处理，内容简述]，[数量]个，错落排列，作为背景层，
各元素之间有前后遮挡关系，制造层次和纵深，

压在人物和前景元素之间，与多个层次形成遮挡关系，

```

## 风格七：人物侧置留白风

人物偏一侧，对面留大面积空间给标题，版面对比强大气。

- 人物：偏左或偏右，占宽 25-35%，眼神与身体朝向留白区。
- 留白区：占 60-70%，标题占满，大而有力；字体深色为主。
- 背景：中性或浅色；标题可竖排或横排。
- 人物：参考图1。

提示词模板：

```text
参考图1的[性别]五官特征，保持五官一致性，只要半身。
人物置于画面[左/右]侧，占画面宽度约30%，[具体姿势]，
[具体表情]，眼神和身体自然朝向[对侧留白区]，
画面[对侧]约65%是大面积留白，
超大中文"[封面标题]"占满留白区域，[字体风格]，[颜色：深红/深灰]，
[排列方式：竖排从上到下/横排分两行/主字大副字小等]，
[如有补充信息：一行小字灰色在标题下方]
背景：[中性或浅色色调，整体柔和]
人物与文字之间保留足够的呼吸距离，不拥挤，不超出安全区
```

## 风格八：背影构图风

人物背对镜头，不露脸，制造代入感，适合励志、开放、新开始类内容。**无需人脸参考图。**

- 人物：背影，只见后脑、肩膀、背部，有动势。
- 前方：人物朝向的目标或主视觉元素。
- 背景：大气、开阔、有纵深感（通常深色）。
- 字体：在人物上方，宽松舒展。

提示词模板：

```text
[性别]人物背对镜头，只见后脑、肩膀和背部，发丝清晰，不露脸，
[具体动作：仰头看向前方/双臂展开/缓步向前等]，[身体姿势描述，有动势感]，
人物前方[或上方]是[主视觉元素的详细描述：内容/大小/状态/动态]，
[主视觉元素和人物之间的空间关系描述]，
巨大的中文大字"[封面标题]"在人物[上方/左右两侧]，[字体风格]，[颜色效果]，
字间距宽松，与背景有足够对比，
背景：[大气深色渐变，营造开阔纵深感]
画面有[叙事感描述：释放/出发/到达等]，代入感强，不超出安全区
```

## 风格九：局部出镜风

只露手、半脸或侧脸，产品或文字是绝对主角。**无需完整人脸参考图**（有局部照片更佳）。

- 产品/截图：占画面主体，清晰锐利，细节可读。
- 人物：局部出镜，占边缘 15-25%，不喧宾夺主。
- 背景：浅色/中性；字体压在产品顶部或旁边。
- 人物：参考图1，只露局部（手/半脸/侧脸）。

提示词模板：

```text
画面主体是[产品/截图/卡片的详细描述：内容布局/颜色/关键信息]，
占画面约[比例]，白底或[底色]，清晰锐利，
（如有图2：主体内容即参考图2，[图2的展示方式]）
画面[右下角/左侧边缘/底部边缘]局部出镜：
参考图1的[手部特写/半张脸/侧脸轮廓]，
[具体局部动作：食指轻触/拿起/指向某个位置]，
[局部出镜的细节：手的姿势/脸的朝向/与主体的距离关系]，
"[封面标题]"，[字体风格]，[颜色效果]，压在主体[上方/左侧/下方]
背景：[浅色/中性色，让主体成为绝对焦点]
产品是焦点，人物只是见证者，不超出安全区
```

## 风格十：正面对视风

人物直视镜头建立眼神接触，文字上下夹住脸部四周，情绪直接强烈。**必须有图1 人脸参考图。**

- 人物：正面居中，直视镜头，脸部是视觉核心。
- 文字：上下两行夹住脸部，不遮挡眼睛和嘴巴。
- 背景：高饱和纯色或深色渐变。
- 人物：参考图1，正面居中。

提示词模板：

```text
参考图1的[性别]五官特征，保持五官一致性，半身，正面直视镜头。
[具体表情描述，情绪要强烈明确]，[手/身体的配合姿势]，与观众形成强烈眼神接触，
"[封面标题前半]"[字数]个字在人物脸部上方，[字体风格]，[颜色效果]，字号极大，
"[封面标题后半]"[字数]个字在人物脸部下方，[字体风格]，[颜色效果]，略小，
两行文字上下夹住脸部，形成自然框架，不遮挡眼睛和嘴巴，文字与脸部有呼吸距离，
（如有点缀：脸部两侧各一个极小[主题图标]飘浮，轻微投影）
背景：[色调，高饱和纯色或深色渐变，与人物形成高对比]
人物是绝对焦点，画面直接有力，情绪满溢，不超出安全区
```

## 通用提示词规范

- 具象隐喻：抽象概念优先找日常可识别的实物（如"成本下降"→ 滑梯/瀑布，不用数据流）。
- 不要发光特效：全息投影、数据流、粒子效果容易让画面廉价。
- 正向描述：只写画面里应该出现什么。
- 参考图指代：直接写"图1/图2/图3"，不复述图里所有细节。
- 每种风格有自己的背景和字体逻辑：不要把同一套颜色字体套到所有风格。
- 图内文字严格限制：封面标题（4-8 字）+ 公众号 21:9 可加一行副标题；禁止数字、标签、链接、正文句。
