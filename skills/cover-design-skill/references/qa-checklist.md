# 封面规格质检清单

## 必跑命令

```bash
python3 skills/cover-design-skill/scripts/check_cover_specs.py <图片路径或目录> [--type xhs|gzh-cover21|gzh-square|gzh-inline|auto]
```

规格 FAIL 必须修复后重出；WARN 需人工确认。

## 平台规格

### 小红书封面（xhs）

- [ ] 尺寸 1080×1440（3:4）精确达标。
- [ ] 底部内容留白 ≤120px，禁止大面积空档。
- [ ] 四周安全边距 ≥80px，元素不超出安全区。
- [ ] 标题 3 秒可懂；无 AI 腔、无假数据、无图内长文案。

### 公众号封面

- [ ] 21:9 主封面 + 1:1 方封面成对交付，禁止一张图盲裁两版。
- [ ] 21:9：主标题 + 一行副标题 + 一个强视觉关系。
- [ ] 1:1：简化短标题（用 `guizang-social-card-skill` 的 title-shortener 逻辑），大字号居中。

### 公众号正文插图

- [ ] 宽高比 ≥1.6:1（16:9 或更宽），禁止竖向长图。
- [ ] 竖图用 `sips -c <高> <宽>` 中心裁切，原图保留在 `_source/`。
- [ ] 流程/结构图用 HTML 画布（1500px 宽）渲染，不用 AI 生图。

## 提示词反模式（命中即返工）

- 发光 / 全息 / 粒子 / 数据流特效。
- 否定句（"不要…"、"避免…"）。
- 模糊动作（"做一个动作"、"摆个姿势"）。
- 图内长文案、标签、数字、链接。
- 无用户参考图时编造真人脸。
- 假数据 / 假统计 / 假截图。

## 人工目检（交付前）

- [ ] 缩到 360px 宽仍能读懂标题。
- [ ] 标题无遮挡、无断行、不出安全区。
- [ ] 无 >15% 画布的纯空白带（有留白理由除外）。
- [ ] 无廉价贴纸式点缀、无发光特效。
- [ ] 红白品牌色一致（用户另选色调除外）。
- [ ] 参考图路径与合成方式已在交付说明中如实标注。
