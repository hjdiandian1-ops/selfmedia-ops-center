# 色相环与配色方案

## HSV 基础

- H（色相 0-360）：决定“是什么颜色”。
- S（饱和度 0-1）：决定鲜艳度。
- V（明度 0-1）：决定亮暗。
- 转 HSV：`max(r,g,b)` 为 V，`(max-min)/max` 为 S，按 max 分量定位 H。

## 五种配色方案

| 方案 | 色相差 | 效果 | 适用 |
| --- | --- | --- | --- |
| 单色 monochromatic | 0°（只变 S/V） | 统一克制 | 层级/深浅 |
| 近似 analogous | 30-45° | 和谐柔和 | 品牌基调 |
| 分裂互补 split-complementary | 150°/210° | 有对比又不刺眼 | 主色 + 2 协调色 |
| 互补 complementary | 180° | 强烈冲击 | 强调/CTA |
| 三角 triadic | 120° | 活泼均衡 | 三平台对比 |

## 推荐：主色 + 3 协调色

- 方案 A（数据看板）：`主色 + 120° + 240° + 主色深阶`，保证 4 条序列肉眼可分。
- 方案 B（品牌风）：`主色 + 相邻 2 个 35° 近似色 + 150° 对比色`，整体协调又有记忆点。
- 数据可视化另用 Okabe-Ito 色盲安全 8 色作为兜底，避免只靠色相传达信息。

## HSV 偏移公式

给定主色 H0、S0、V0：

- 色相偏移：`H = (H0 + delta) % 360`，S/V 保持或微调（±0.05）。
- 深阶：`V = V0 * 0.72`，S 不变。
- 浅阶（容器）：`V = V0 + (1 - V0) * 0.75`，S 降为 `S0 * 0.55`。

## 色相差目标

- 同屏 2 色：≥60°
- 同屏 3 色：≥90°
- 同屏 4 色：≥80°（且避免两两 <40° 的近似对，除非刻意同族层级）
