# 范文库（爆款反哺 · Few-Shot 资产）

> **定位**：数据验证过的爆款文章解剖库，是 `personal-style-guide.md` 的**活教材**。
> 规则 > 示例：风格指南告诉 AI "怎么写"，范文库告诉 AI "这样写是有效的"——**示例比规则有效 10 倍**。

---

## 入库门槛

发布 48h 后回收数据达到爆款阈值（默认：**阅读 ≥ 5000 或 点赞 ≥ 200**，见 `collect_post_stats.py`）。

## 入库流程

```bash
# 1. 回收数据（达阈值会提示）
python3 scripts/collect_post_stats.py <job_id> --platform 小红书 --reads ... --likes ...

# 2. 生成解剖骨架（自动预填元数据）
python3 scripts/init_hit_anatomy.py <job_id>

# 3. 由「资深校对排版」或「总编」完成解剖分析（LLM 任务，逐段填写）
# 4. 在 personal-style-guide.md 的范文索引中登记一行
```

## 解剖模板（init_hit_anatomy.py 自动生成此骨架）

每篇范文解剖必须包含：

1. **元数据**：Job、平台、数据表现、标题公式编号、消费的素材条目
2. **标题解剖**：命中哪个公式、哪个心理触发器、为什么有效
3. **Hook 解剖**：开篇用了什么素材、制造了什么悬念
4. **结构解剖**：段落级标注——这段为什么是钩子/数据/转折/金句
5. **可复制规则**：提炼 1-3 条**可迁移到下篇**的写作规则（回写 style-guide 候选）

## 使用规则

- 主编创作时，**先读本库同平台最新 1-2 篇范文解剖**，再动笔（few-shot 注入）。
- 范文库只收**数据验证过**的文章；未达阈值的文章不得入库（防止主观偏好污染）。
- 解剖中提炼的「可复制规则」经用户确认后，才回写进 `personal-style-guide.md` 正式规则区。
