# 爆款拆解 Skill

## 输入
- 标题（必填）
- 原文：笔记正文 / 视频逐字稿 / 长文（可部分）
- 链接（可选）
- 平台（可选：小红书/抖音/B站/视频号/X/公众号/其他）
- 热度/排名（可选：来自榜单的 score/hot_value/阅读量）

## 平台拆解重点（按平台聚焦，不要每项都写满）
- **小红书**：封面/首图点击率是第一道闸；标题是否埋搜索词；内容是否有收藏价值（清单/教程/避坑）与评论话题；情绪与人群是否精准。
- **抖音**：前 3 秒钩子决定完播；信息密度与节奏决定停留时长；收藏/关注/评论等深度行为权重大于浅赞；选题是否有搜索价值。
- **公众号**：标题是否清晰完整、主题明确（少故弄玄虚）；开头是否快速给结论；观点/真实案例是否有转发欲；是否埋长尾搜索关键词。

## 拆解维度（每项都要给具体证据，不许空话）
1. **前 3 秒钩子**：开头怎么抓人（数字/冲突/反常识/提问/身份代入）。
2. **选题角度**：为什么这个选题会有人看；蹭了什么热点/情绪/人群。
3. **内容结构**：段落/分镜顺序，起承转合，信息密度安排。
4. **情绪与人群**：主打情绪（焦虑/好奇/共鸣/爽感）、目标人群。
5. **金句与留存节点**：每 10-15 秒/段落的记忆点，让人想看完或收藏。
6. **剪辑节奏**（视频才填）：镜头切换、字幕、BGM、卡点；图文则写排版节奏。
7. **转化设计**：点赞/收藏/评论/关注/进主页的引导动作。
8. **公式标签**：从下面选 1-3 个：数字冲击 / 反常识 / 身份代入 / 悬念好奇 / 干货清单 / 冲突对比 / 社会证明 / 蹭热点时效 / 实操教学。

## 输出（严格按此执行）
1. 把结果 JSON 写到 `data/flywheel/breakdowns/<viral_id>.json`：
```json
{
  "title": "原标题",
  "platform": "小红书",
  "evidence_level": "title_only",
  "hook": "前3秒钩子拆解",
  "structure": "结构拆解",
  "why_viral": "爆点归因（含证据）",
  "formula": "公式1, 公式2",
  "summary": "一句话总结为什么火、能复用什么"
}
```
2. `evidence_level` 取值：`content`（有正文/逐字稿）｜ `title_only`（仅标题与热度/榜单上下文）｜ `mixed`（部分原文）。`title_only` 时所有维度均为“推断”，必须在 `why_viral` 中标注“基于标题推断”，不得编造具体数据、封面细节或逐字内容。
3. 同时写 `data/flywheel/breakdowns/<viral_id>.md`，格式为“## 拆解报告”+ 八个维度小节+依据级别，供人读。
4. 最后在输出里给出一段 ≤200 字的“可复用创作指令”，不要写进 JSON。

## 纪律
- 只基于提供的原文/链接内容拆解，不编造数据；链接无法访问就注明“未获取原文，基于标题与输入拆解”。
- `title_only` 的拆解定位是“选题角度与公式推断”，不是事实复述；禁止编造作者、数据、画面或文案细节。
- 不写完整复制稿；只提炼方法与公式。
