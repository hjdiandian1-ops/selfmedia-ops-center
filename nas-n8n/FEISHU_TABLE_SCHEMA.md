# 📊 飞书多维表格【小吴聊 - 爆款选题雷达库】搭建指南

为了将全网抓取的 AI / 极客 / 科技爆款热点转化为可持续生产的内容资产，建议在飞书创建一个名为 **`【小吴聊】爆款选题雷达库`** 的多维表格。

---

## 📋 建议数据表结构 (Table Fields)

| 字段名称 | 字段类型 | 详细说明 / 选项设置 |
| :--- | :--- | :--- |
| **选题标题** | 文本 (Single Line) | 自动抓取到的文章/热榜标题 |
| **来源平台** | 单选 (Single Select) | 选项：`36Kr` / `GitHub Trending` / `Hacker News` / `微信公众号` / `小红书热榜` / `X (Twitter)` |
| **爆款热度分** | 数字 (Number) | LLM 根据阅读量、转发数、讨论度评分 (0 - 100) |
| **AI 核心摘要** | 多行文本 (Text) | LLM 自动提取的 3 句话极简摘要（含受众痛点） |
| **推荐创作方向** | 多选 (Multi Select) | 选项：`AI工具测评` / `硬核架构避坑` / `效率提升` / `市场复盘` / `极客实操` |
| **适用平台** | 多选 (Multi Select) | 选项：`公众号` / `小红书` / `双平台发版` |
| **选题状态** | 单选 (Single Select) | 选项：`🆕 待筛选` -> `📌 已采纳` -> `✍️ 创作中` -> `✅ 已发布` -> `🗑️ 归档/忽略` |
| **原始链接** | 超链接 (URL) | 原新闻/文章/开源项目 URL 地址 |
| **抓取时间** | 日期时间 (Date) | 自动写入抓取到表格的时间 |

---

## 🤖 n8n 自动化写入字段映射配置

在 n8n 的 `Feishu / Lark Node` 或 `HTTP Request Node` 中，写入 Payload 格式如下：

```json
{
  "fields": {
    "选题标题": "={{ $json.title }}",
    "来源平台": "={{ $json.source }}",
    "爆款热度分": "={{ $json.score }}",
    "AI 核心摘要": "={{ $json.ai_summary }}",
    "推荐创作方向": ["AI工具测评", "极客实操"],
    "适用平台": ["小红书", "公众号"],
    "选题状态": "🆕 待筛选",
    "原始链接": "={{ $json.url }}"
  }
}
```
