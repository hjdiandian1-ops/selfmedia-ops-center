# 📦 素材资产库：Grok 4.6「半价追平 OpenAI」素材包

**分类**：#Grok #xAI #SpaceXAI #OpenAI #大模型 #API定价 #AI资讯

---

## 🔍 一、 对标拆解 (dbs-benchmark)

- **痛点对标**：8 月 12 日（北京时间晚）SpaceXAI 发布 Grok 4.6，第三方 Artificial Analysis 智能指数 61 分追平 OpenAI GPT-5.6 Sol，而 API 定价 2/6 美元（百万 token），不到 GPT-5.6 Sol 的 5/30 美元一半。主流报道都在喊「性价比炸裂」，很少有人回答：这个「半价」叙事有哪些暗坑（20 万 token 翻倍、终端任务落后、品牌治理包袱）？「每 token 便宜」和「每任务便宜」到底哪个才是真账本？（source_type: AI推断 | priority: 辅助）
- **差异化切入点**：用「账本」结构拆三笔账——单价账（2/6 vs 5/30，便宜 60%+）、任务成本账（53 回合 vs 103 回合，每任务 0.84 美元）、隐藏成本账（20 万 token 后翻倍、缓存价上涨 67%、企业合规风险）。不吹不黑：跑分追平是真的，但「全面碾压」是假的。（source_type: AI推断 | priority: 辅助）

## 🛠️ 二、 核心素材与数据清单

- **M1｜智能指数 61 分追平 GPT-5.6 Sol，单月涨 5 分**：第三方 Artificial Analysis Intelligence Index 给 Grok 4.6 打 61 分，追平 OpenAI GPT-5.6 Sol（61 分）与 GPT-5.6 Sol Max（61 分）；Anthropic Claude Fable 5 为 62 分、Claude Opus 5 为 63 分，仍占据前两名。对比一个月前的 Grok 4.5（56 分），单月提升 5 分；SpaceXAI 称在「智慧、速度和成本」三方面综合下 Grok 4.6 客观上排名第一。（source_type: 真实数据 | priority: 核心）
  - 来源：https://the-decoder.com/spacexais-grok-4-6-matches-openais-best-model-and-undercuts-it-on-price/；https://venturebeat.com/technology/spacexai-debuts-grok-4-6-overtaking-kimi-k3s-performance-and-matching-gpt-5-6-sol-for-worlds-third-best-on-artificial-analysis；https://www.stheadline.com/zh-hans/realtime-finance/3603872/
- **M2｜API 定价 2/6 美元，比 GPT-5.6 Sol 便宜 60% 以上**：Grok 4.6 API 起步价每百万输入 token 2 美元、每百万输出 token 6 美元（prompt 低于 20 万 token 时）；缓存输入 0.5 美元/百万 token；另提供速度更快的版本，价格为标准版 2 倍（4/12 美元）。对比 OpenAI GPT-5.6 Sol 标准模式 5/30 美元、Claude Opus 5 的 5/25 美元，输出单价便宜 76-80%，综合便宜 60% 以上；多家媒体标题写「半价追平」。（source_type: 真实数据 | priority: 核心）
  - 来源：https://venturebeat.com/technology/spacexai-debuts-grok-4-6-overtaking-kimi-k3s-performance-and-matching-gpt-5-6-sol-for-worlds-third-best-on-artificial-analysis；https://www.jiemian.com/article/14914370.html；https://www.edgen.tech/zh/news/post/grok-46-matches-frontier-rivals-at-half-the-price
- **M3｜Agent 任务效率：53 回合完成 vs Claude Opus 5 的 103 回合**：Artificial Analysis 在 AA-Briefcase 长程知识工作基准上测得，Grok 4.6 平均约 53 个回合、约 5 亿输入 token 完成一个任务；Claude Opus 5 约需 103 回合、约 20 亿输入 token。GDPval-AA v2 上 Grok 4.6 Elo 1753，排名第二，仅次于 Claude Opus 5；每任务成本约 0.84 美元，与 Kimi K3 持平，位于「智能 vs 成本」Pareto 前沿。（source_type: 真实数据 | priority: 核心）
  - 来源：https://the-decoder.com/spacexais-grok-4-6-matches-openais-best-model-and-undercuts-it-on-price/；https://developer.aliyun.com/article/1755372；https://venturebeat.com/technology/spacexai-debuts-grok-4-6-overtaking-kimi-k3s-performance-and-matching-gpt-5-6-sol-for-worlds-third-best-on-artificial-analysis
- **M4｜上线渠道与首周双倍额度：Cursor、Grok Build、API、OpenRouter、Vercel、Cloudflare**：Grok 4.6 发布当日在 Cursor 与 Grok Build 上线（Grok Build 含在每月 30 美元的 SuperGrok 计划内），也可通过 API 及 OpenRouter、Vercel、Cloudflare 调用；首周在 Cursor 和 Grok Build 提供双倍使用额度。支持 50 万 token 上下文窗口（文本+图像输入、文本输出），限流 150 次请求/秒、5000 万 token/分钟。（source_type: 真实数据 | priority: 核心）
  - 来源：https://venturebeat.com/technology/spacexai-debuts-grok-4-6-overtaking-kimi-k3s-performance-and-matching-gpt-5-6-sol-for-worlds-third-best-on-artificial-analysis；https://www.jiemian.com/article/14914370.html；https://www.stheadline.com/zh-hans/realtime-finance/3603872/
- **M5｜性价比真相：并非全胜 + 20 万 token 翻倍暗坑**：分项基准上 Grok 4.6 有赢有输——CursorBench v3.2 编程 69.9%（高于 GPT-5.6 Sol Max 的 67.2%，但低于 Fable 5 Max 的 70.5%）；APEX-Agents 57.5% 小幅超过 Sol Max 的 56.7%；但 DeepSWE 65.9% 落后 Sol Max 的 73.0%，Terminal-Bench v3.0 仅 26.0% 落后 Sol Max 的 34.6%。定价暗坑：prompt 达到 20 万 token 后费率翻倍（4/12 美元），且整笔请求按翻倍价计费，不是只算超出部分。（source_type: 真实数据 | priority: 核心）
