## 🔍 一、 对标拆解 (dbs-benchmark)

- **痛点对标**：全网都在追新模型、新工具，但工具数量已经多到一个人学不过来；真正的差距不再是「会不会用 AI」，而是「能不能把老师傅的经验打包成 AI 可复用的 Skill」。本篇不谈“哪个模型强”，谈“Skill 是什么、谁在押注、怎么开始”。（source_type: AI推断 | priority: 辅助）
- **差异化切入点**：与已发选题错开——08-06 拆 token 价格、08-07 拆视频门槛、08-08 拆个人工具配置账本，今天拆**能力封装层**：Skill 开放标准、Meta Skill 编排、私有技能资产化。（source_type: AI推断 | priority: 辅助）
- **📕 封面套路观察**：GitHub 一夜 +2000 星 / 复旦 16 分钟 96 样本 这类反差数字，配「AI 的下一个风口」式定调，红白强对比，主数字占版面 1/3。（source_type: AI推断 | priority: 辅助）

  - 来源：https://www.pingwest.com/a/312295（品玩 2026-03-20）
- **M2｜Meta Skill：Skill 的 Skill，OpenSquilla 发布 9 个封装好的 Meta Skill**：量子位 2026-06-03 报道，GitHub 热门仓库 OpenSquilla 发布 Meta Skill 功能（仓库当时 2000+ 星）。一个 Meta Skill 内嵌多个 Skill，拼接成「超级白皮书」，能端到端打通一整套长程 Workflow；内置智能模型路由，同类任务 Token 成本比主流 Agent（龙虾）省 60-80%；实测 meta-kid-project-planner 由 5 个原子 Skill 拼接，SKILL.md 400+ 行，全程无需人介入跑 20+ 分钟，交付 7 天项目规划包（约 3000 字）。（source_type: 真实数据 | priority: 核心）

- **M3｜reverse-skill：GitHub 日榜第一，17.7k 星、单日 +2258**：2026-08-04 GitHub 日榜最佳项目 zhaoxuya520/reverse-skill，5 月 13 日开源，8 月 4 日总星标 17,677、单日 +2,258、上周 +7,077；8 月 5 日突破 18,500 星、24h +2,297 冲上 GitHub Trending。把 20+ 逆向工程场景标准化为 Skill 包：AI 自动路由 + 工具链按需自举 + field-journal 经验库自进化，支持 Claude Code / Kiro / Cursor / Cline。（source_type: 真实数据 | priority: 核心）

- **M4｜Skills 标准化时间线：Claude 2025-10-16 发布，12-18 Anthropic 转开放标准，OpenAI/微软/腾讯跟进**：新京报贝壳财经 2026-01-22 实测报道——Claude Skills 2025 年 10 月 16 日发布；12 月 18 日 Anthropic 宣布 Skills 成为开放标准；同月 ChatGPT 出现几乎相同架构（相同 SKILL.md、目录组织），微软、腾讯跟进；截至 1 月 21 日 Anthropic 官方 Skills 库星数接近 5 万；Anthropic 核心工程师 Barry Zhang 在行业论坛说「别造 Agent 了，造 Skills 就行」。（source_type: 真实数据 | priority: 核心）
  - 来源：http://www.bjnews.com.cn/detail/1769047462168003.html（新京报 2026-01-22）
- **M5｜渐进式加载：100 个技能平时几乎不占上下文；Skill 与 MCP 是互补不是替代**：Anthropic 设计 Progressive Disclosure 机制——AI 启动时只扫每个 Skill 的元数据（约 100 tokens），需要时才加载完整 SKILL.md（约 3000 tokens）和相关脚本；一个 Agent 可装备 100 个技能，平时几乎不占用上下文。Skill 是静态可移植的说明书（markdown + YAML frontmatter，教 Agent「怎么做」），MCP 是实时工具访问协议（给 Agent「能访问什么」）；Sentry 联合创始人 David Cramer 的比喻：Skill 教你做饭，MCP 给你厨具。（source_type: 真实数据 | priority: 核心）
  - 来源：http://www.bjnews.com.cn/detail/1769047462168003.html（新京报 2026-01-22）；https://atlan.com/know/ai-agent/ai-agent-skills/agent-skills-vs-mcp/（Atlan 2026-07-16）

## 📎 三、 辅助素材

- **A1｜普通人用 Skill 的实证：花叔的自动化写作，4800 人安装**：新京报实测报道中，「花叔的自动化写作」技能已有 4800 人安装，创作者表示该技能「运行迭代 2 个月 20 版以上，产出 10 篇以上 1 万+ 阅读文章」。（source_type: 真实数据 | priority: 辅助）
  - 来源：http://www.bjnews.com.cn/detail/1769047462168003.html（新京报 2026-01-22）
- **A2｜风险提示：个人开发的 Skill 可能藏恶意代码**：新京报采访开发者提示，GitHub 上名字、功能五花八门的 Skills 中有可能隐藏恶意代码、脚本，存在信息泄露风险；创建独属于个人或公司的私有技能最保险。本篇不展开任何攻击性细节。（source_type: 真实数据 | priority: 辅助）
  - 来源：http://www.bjnews.com.cn/detail/1769047462168003.html（新京报 2026-01-22）
- **A3｜OpenAI Codex Skills 官方文档（SKILL.md 标准）**：Codex 会自动发现磁盘上可复用的 skills，每个 skill 包含名称、简短描述（何时使用）、可选正文指令；注入机制只加载名称与描述，正文按需打开。（source_type: 真实数据 | priority: 辅助）
  - 来源：https://github.com/openai/codex/blob/main/docs/skills.md（OpenAI 官方）
- **A4｜Anthropic 内部实践：Claude Code 团队把工作流沉淀为 Skills**：Anthropic 官方博客 2026-06《Lessons from building Claude Code: How we use skills》，工程团队将代码脚手架、代码质量与审查、CI/CD 等 7 类内部工作流封装为 Skills；说明「把隐性流程显性化」正在成为 AI 工程团队的标配。（source_type: 真实数据 | priority: 辅助）
  - 来源：https://claude.com/blog/lessons-from-building-claude-code-how-we-use-skills（Anthropic 官方）
- **A5｜小吴聊实证（用户投喂，只写一段）**：小吴自己的 NAS 内容工厂——RSSHub 热点雷达 + Job 状态机 + 双轨质检 + 公众号官方草稿 API + 小红书人工素材包，每天三档跑生产，人工只出现在选题和发布 2 个卡点；整套流水线本质上也是「把主编经验写成 SKILL.md + 用状态机编排」的一次落地。本篇即是该流水线 2026-08-08 晚档的产出。（source_type: 用户投喂 | priority: 辅助）
- **A6｜合规口径**：本篇只拆公开机制与公开数据，不推荐具体投资标的；安全/逆向类 Skill 仅引用社区热度与机制设计，不展开操作细节，国内合规可发布。（source_type: AI推断 | priority: 辅助）
