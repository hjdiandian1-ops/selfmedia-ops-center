# 发布与后台配置手册（面向新手）

> 工作台负责把内容生产好，发布动作仍由你在各平台完成。本文按平台说明手动发布和自动推送两种方式。

## 一、小红书（手动发布）

1. 打开「成品库」，选择任务，切到「小红书」页签；
2. 点「复制标题」（已控制 ≤20 字）和「复制正文」（≤1000 字）；
3. 打开小红书 App → 发布图文：粘贴标题和正文，上传卡片图片（卡片在产物目录 `outputs/<任务>/小红书/` 的 xhs-*.png）；
4. 至少添加 5 个相关标签（正文末尾可自带）；
5. 发布后回到工作台「成品库」点「标记已手动发布」；
6. 48 小时后在「概览 → 保存回填」填写阅读/赞/藏/评，数据才会进入飞轮。

## 二、微信公众号

### 方式 A：手动发布（所有人可用，无需认证）

1. 打开「成品库」，切到「公众号」页签，下载/打开排版 HTML；
2. 登录微信公众平台（mp.weixin.qq.com）→「图文消息」→ 新建图文；
3. 用浏览器打开排版 HTML，全选复制，粘贴到编辑器（或使用编辑器工具栏的「导入」）；
4. 填入标题、摘要、封面，保存为草稿或直接群发；
5. 回工作台「标记已手动发布」并按时回填数据。

### 方式 B：自动推送到草稿箱（仅已认证公众号）

需要满足三个条件：

1. 公众号为**已认证**的订阅号或服务号（个人/未认证订阅号无法使用 API）；
2. 在微信公众平台 →「设置与开发」→「基本配置」中获取 **AppID** 和 **AppSecret**，并点击「修改」配置 **IP 白名单**（填你电脑的公网 IP；可从 ipip.net 等网站查询）；
3. 在工作台左下角「⚙ 设置」填入 AppID / AppSecret 并保存。

然后在「成品库」选择任务，点「推送到公众号草稿箱」，草稿会出现在公众平台的草稿箱，人工检查后群发。

> 如何确认是否认证：公众平台 →「设置与开发」→「公众号设置」→「账号详情」，账号主体显示「认证」字样即为认证号；个人订阅号没有 API 权限，只能用方式 A。

## 三、短视频（手动发布）

1. 打开「成品库」，切到「短视频」页签，读取 120s 分镜脚本；
2. 按脚本拍摄/剪辑（可用剪映等工具）；
3. 上传抖音/视频号/B站，填写标题与话题；
4. 发布后回工作台「标记已手动发布」，48 小时后回填播放/互动数据。

## 四、发布后必做：数据回填（数据飞轮的燃料）

1. 「概览」页 →「保存回填」；
2. 选择任务与平台，填写阅读/播放、点赞、收藏、评论；
3. 保存后，这些数据会进入大盘统计和薄弱点诊断，并能在「数据飞轮」沉淀为经验反哺 Agent。

## 五、常见问题

**Q：没有 API Key 能发布吗？**
能。发布是手动动作，不需要 AI；AI Key 只影响「AI 拆解」和「一键自动生产」。

**Q：推草稿报「未配置公众号」？**
个人订阅号不支持 API，只能用方式 A 手动发布；已认证号请检查 AppID/Secret 与 IP 白名单。

**Q：发布后数据忘填了？**
工作台「概览」会标记「待回收」，跑 `--recycle` 或等每日任务提醒你回填。
