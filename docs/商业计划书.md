# 自媒体运营工厂 Pro Skill · 商业计划书

> 版本：v1.0 ｜ 日期：2026-08-14 ｜ 产品：小吴聊·自媒体运营工厂 Pro Skill 包（订阅制）

## 1. 一句话定位

把「选题 → 生产 → 分析 → 学习」的完整自媒体运营闭环打包成一个 Codex/Claude 可加载的 Skill 套装，让个人自媒体和小团队用一套提示词工厂就能持续产出高质量内容，并通过数据飞轮越用越强。

## 2. 目标客户

| 客群 | 画像 | 核心痛点 | 购买动机 |
|---|---|---|---|
| 个人自媒体（主） | 小红书/公众号图文作者，AI 用户，月更新 4-12 篇 | 选题靠灵感、排版丑、内容有 AI 味、数据不会复盘 | 一键生产 + 质检闭环，省 70% 时间 |
| 自媒体培训班学员 | 报了课但不会落地执行的人 | 方法论停留在课程里 | 拿到就能跑的「工厂」，学完即用 |
| 小团队/工作室 | 2-5 人代运营 | 每人风格不统一、交付质量不稳定 | Agent 分工 + SOP 文档统一标准 |
| 海外用户（远期） | Claude Code 用户 | 同上的英文版需求 | 英文版 Skill 包 |

## 3. 竞品分析

| 竞品 | 模式 | 抽成/价格 | 与我们的差异 |
|---|---|---|---|
| Loreto（skill 市场） | 付费 skill 市场 | 平台抽 20% | 只做分发，不提供完整运营方法论 |
| AgentPowers | MCP 市场 | 订阅+抽成 | 偏开发者工具，非自媒体垂直 |
| ClaudSkills | 注册表+Pro 会员 | $9/月 | 是「目录」，不是「工厂」 |
| 闲鱼/淘宝同行 | 卖提示词模板 | 9.9-99 元一次 | 无更新、无质检、无数据闭环 |
| 知识星球/小报童课程 | 课程+社群 | 199-999 元 | 知识付费，非工具；我们交付可运行资产 |

**差异化壁垒**：① 完整运营方法论（报社式 Agent 分工）；② 机器可算质检链（Harsh Critic + 去 AI 味 + 合规）；③ 数据飞轮（发布数据反哺 Agent SOP）；④ 三平台爆款跟踪 + AI 拆解。

## 6. 渠道与获客

1. **GitHub 开源核心引流**：公开仓库展示工作台能力（免费模块可直接跑），README 挂 Pro 包购买入口 → SEO + 社区口碑。
2. **内容营销**：用工厂自己生产「如何用 AI 工厂做自媒体」系列内容（小红书 + 公众号），成品即广告。
3. **面包多**：Pro 商品自动发货（卡密 token），搜索「AI 写作」「自媒体工具」长尾词。
4. **闲鱼**：挂「授权激活服务」链接，话术走服务类目，冷启动期人工发码。
5. **社群/知识星球**：给星球主分销码（20% 分成），批量触达培训班学员。

|---|---|---|---|
| 注册用户 | 1,000 | 5,000 | 15,000 |

## 9. 风险与对策

| 风险 | 等级 | 对策 |
|---|---|---|
| 盗版/文件转发 | 中 | token 绑设备指纹；付费文件不公开分发；法律声明「个人非转让许可」 |
| 闲鱼风控/封号 | 中 | 以「授权激活服务」名义上架；主要渠道放在面包多 |
| 第三方 skill 版权 | 高 | 付费包只含自有内容；第三方 skill 仅给链接，不打包 |
| 平台政策（AI 内容标识等） | 中 | 合规审核为 Pro 核心卖点，随平台规则更新 |
| 依赖 Codex/Claude 生态 | 中 | 生产引擎可扩展（预留 DeepSeek API 适配） |

## 10. 路线图

- **v1（本期）**：GitHub 公开仓库 + 付费包 + 离线签名 token + 面包多/闲鱼上线。
- **v2（有 50+ 付费用户后）**：在线激活/换绑/吊销接口；自动发货 token；多设备（2 台）与团队席位。
- **v3**：企业版（商用许可+部署支持）；英文版 Skill 包；可选 DeepSeek 生产引擎。
