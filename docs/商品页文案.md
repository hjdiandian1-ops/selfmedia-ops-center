- 合规审核 + 去 AI 味质检全套
- 公众号草稿推送、发布数据回收

**免费版能体验**：选题雷达基础源、基础排版模板、每月 3 次爆款 AI 拆解。

**授权说明**
- 本商品为「个人非转让授权」，一个授权绑定一台设备；
- 禁止对授权内容（Skill 文件、SOP、范文、风格指南、经验库）进行 AI 训练、蒸馏、二次分发或打包进其他产品/模型；

- 严禁转卖、共享授权；发现多设备共用将回收授权。

**公众号推送提示**：自动推送到公众号草稿箱需要「已认证公众号 + AppID/Secret + 电脑公网 IP 白名单」，这些配置需要你在微信公众平台（mp.weixin.qq.com）自行操作，详见随包《发布与后台配置》手册；个人订阅号不支持，可选手动发布。

1. 收到 token 后，在 Skill 包目录运行 `python3 scripts/license/install.py --show-fingerprint`，把设备码发给客服；

3. 提示「授权激活成功」即可使用 Pro 功能。
