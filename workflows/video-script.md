## 〇、 脚本 → 成片：video_compose.py 快剪合成（2026-08-04 起生效）

分镜脚本定稿后，可直接本机零成本合成 MP4（路径 B：卡片 + TTS + ffmpeg）：

```bash
# 1. 准备 video_shots.json（每镜：卡片图 + TTS 台词 + 花字）
#    图片优先复用小红书 3:4 卡片；台词改写为 TTS 友好写法（数字转中文读法，如 189% → 百分之一百八十九）
# 2. 一键合成（venv python，含 imageio-ffmpeg 静态二进制）
python3 scripts/video_compose.py outputs/<job_id>/短视频/video_shots.json \
    -o outputs/<job_id>/短视频/<标题>_快剪v1.mp4
```

- **机制**：macOS `say` TTS（默认 Tingting，`-r 160`）→ afinfo 测时长 → 音频驱动镜头长度 → drawtext 烧花字 → concat → SRT 口播字幕（每 2 行一组按字数比例分配时长）。
- **产出**：1080x1440（3:4）MP4，适配小红书/视频号；总时长由台词决定（通常 90-130s，不强行锁 120s）。
- **三档画质路线**：B 快剪（本工具，零成本）→ C 关键镜头换 VideoGen AI 空镜（5s≈50-100 credits）→ A 真人口播重拍（IP 质感终态）。
- **注意**：TTS 有机械感，正式发布建议先在剪映替换真人配音或更高质量 TTS；BGM 需自行叠加（本工具暂不含配乐）。
- 环境：ffmpeg 来自 `imageio-ffmpeg`（venv 已装）；系统 playwright 自带的 ffmpeg 只有 VP8 编码器，不可用于 MP4。

## 一、 三大专栏适用模版

### 🚗 专栏一：【硬核拆解】 (Hardware, EV & AI Cost Analysis)
- **核心视角**：从 BOM 成本、硬件参数、电池/底盘供应链及大模型算力切入，破除营销套路。
- **结构规范**：
  - **0-3s 黄金 Hook**：【画面】车内/拿硬件实拍，【台词】“xx宣称这套配置值10万？今天带大家算算账，实际 BOM 成本连1万都不到！”
  - **3-15s 身份切入**：“我是小吴。今天咱们不听 PPT 吹牛，直接看物理成本和底层逻辑。”
  - **15-60s BOM成本与技术拆解**：参数/电池/芯片硬核数据对比。
  - **60-90s 行业陷阱/认知反转**：“很多人以为买到了性价比，真相是…”
  - **90-120s 避坑建议与金句升华**：“买产品买的是真正价值，不是营销噱头。觉得有用记得点赞关注！”

### 🎙️ 专栏二：【商业对话】 (单店模型与尽调灵魂拷问)
- **核心视角**：像尽调一样灵魂拷问，追问单店模型、账期、净利率与供应链壁垒。
- **结构规范**：
  - **0-3s 黄金 Hook**：【画面】对坐拍桌/递上报表，【台词】“你一年做3个亿，利润率只有2%？你这是创业，还是给供应链打工？！”
  - **3-15s 身份切入**：“今天小吴对话 [嘉宾]，带大家看透真假商业盛景。”
  - **15-60s 单店模型与算账大考**：客单价、复购率、房租人工占比、回本周期大质问。
  - **60-90s 创业避坑与经验反转**：暴露真实死穴（现金流拖垮/营销吞噬）。
  - **90-120s 商业底层启示**：“任何不谈现金流的繁荣都是泡沫。”

### 🌐 专栏三：【商业观察】 (反常识科普与底层逻辑)
- **核心视角**：反常识切入 + 硬核科学/工业底层 + 社会人文升华。
- **结构规范**：
  - **0-3s 黄金 Hook**：【画面】手持反常识道具，【台词】“你真的了解 [日常现象/品牌出海] 吗？今天用数据带你看看真相！”
  - **3-15s 身份切入**：“我是小吴，带你穿透现象看本质。”
  - **15-60s 硬核底层拆解**：供应链/工业流程/科学原理。
  - **60-90s 社会/商业反转**：打破传统误区。
  - **90-120s 人文升华与金句**：“商业的终局是服务人性，科技的尽头是人文关怀。”

## 二、 脚本标准表格格式

生成短视频脚本时，必须使用如下 5 列标准 Markdown 表格：

| 时间轴 | 画面 (Visual) | 镜头/运镜 | 台词/配音 (Voiceover) | 花字 & 音效 |
| :--- | :--- | :--- | :--- | :--- |
| **0-3s** | 主讲人特写/拿成本表 | 快速推镜 (Push-in) | “xx宣称这套配置值10万？今天带大家算算账，实际成本…” | 💥【醒目大字】：真实成本暴晒<br>🎵 音效：警示音 |
| **3-15s** | 切换至小吴个人出镜 | 中景特写 | “我是小吴。今天咱们不听 PPT 吹牛，直接看物理成本和底层逻辑。” | 🏷️ 标签：小吴聊 / 极客操盘手 |
| **15-60s** | 拆解对比图/BOM表格画中画 | 切镜头 + 局部放大 | “首先看第一项：芯片与硬件…实际采购价格只有…” | 📊 画中画显示 BOM 成本表 |
| **60-90s** | 场景切换/产品细节 | 特写/俯拍 | “很多人以为赚到了，其实品牌在后悬挂/模组上偷摸减配了…” | ⚠️ 警告标志音效 |
| **90-120s** | 主讲人看向镜头升华 | 缓慢拉远 (Pull-out) | “买产品买的是真正价值，不是营销噱头。觉得有用记得点赞关注！” | 💡 核心金句总结 |

## 三、 执行步骤 (SOP)
1. **明确选题与专栏**：确定属于【硬核拆解】、【商业对话】还是【商业观察】。
2. **提炼硬核数据**：收集 BOM 成本、财务报表、单店模型或供应链事实。
3. **输出三合一/分镜脚本**：生成上述 5 列格式的 120s 黄金分镜脚本。
4. **同步生成配套图文**：生成小红书 3:4 视觉卡片（封面+拆解表）与公众号长文排版。
