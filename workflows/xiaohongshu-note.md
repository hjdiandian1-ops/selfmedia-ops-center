# 小红书视觉笔记专项工作流 (Xiaohongshu Visual Note Workflow)

> **触发指令**：`生成小红书笔记：主题「XXX」` 或 `优化这篇笔记的视觉与排版`  
> **核心原则**：生活化表达、强视觉冲击、痛点切入、情绪共鸣与即学即用

---

## 核心策略与结构

### 1. 文案框架 (Hook-Value-CTA)
- **前 3 秒钩子 (Hook)**：抛出强反差或直击痛点的问题（如：“不会写代码就不能用 AI？”）。
- **价值拆解 (Value)**：
  - 降低心理门槛（通俗类比）。
  - 给出 3 个场景化开挂案例（用数字清单呈现）。
  - 交付万能 Prompt / 步骤模板。
- **行动引导 (CTA)**：引导评论区回复关键词获取资源、点赞收藏。

---

## 2. 视觉设计引擎 (`guizang-social-card-skill`)

每一篇小红书笔记均配套生成 3:4 比例的高审美视觉卡片（HTML / 网页 PPT 格式）：

### 卡片规范
- **比例**：3:4 纵向卡片（适合手机满屏显示）
- **风格风格选型**：
  - **瑞士极简风 (Swiss Style)**：高反差配色（克莱因蓝/柠檬黄/翡翠绿 + 深色背景）、极细点阵网格、强字号对比。
  - **电子杂志风**：优雅衬线标题 + 卡片化视效。
- **卡片分布**：
  - **Slide 1 封面**：主标题 + 划线旧认知 + 强反差标签
  - **Slide 2 认知刷新**：通俗翻译与类比卡片
  - **Slide 3 实战场景**：3 大用例清单
  - **Slide 4 工具/模板**：万能提问公式卡
  - **Slide 5 金句收尾**：引导互动与个人 IP 总结
- **底部填满（硬门）**：3:4 卡片内容区底部距页脚 ≤120px，禁止底部大空档；布局用 flex 纵向 + 内容区 `flex:1` 撑满，`render_deck_to_images.py` 渲染时自动逐卡检查，超阈值拒绝交付。

---

## 3. 输出交付标准

1. **爆款标题**（已定稿 1 个，≤20 字，包含 Emoji、吸引点击的标点与情绪词；交付文案中不出现多选）
2. **笔记正文**（≤1000 字，纯文本可直贴，禁止 Markdown 符号；分段清晰、适当 Emoji 点缀、重点突出）
3. **视觉卡片预览文件**（如 `rednote_slides.html`）与生成 Prompt 描述
4. **推荐标签**（搜索权重较高的热词与长尾标签组合）
