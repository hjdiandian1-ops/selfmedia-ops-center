# 微信公众号高审美长图文工作流 (WeChat Long-Post Workflow)

> **触发指令**：`生成高审美公众号长文：主题「XXX」`  
> **核心原则**：深度思考、强阅读流畅度、杂志级视觉排版、纯净 HTML 粘贴

---

## 核心流程规范

### 1. 结构与文案设计
- **杂志快讯封面 (Cover Breaking)**：双层标题设计（外标题吸引点击，内封面卖内容价值）。
- **横向导览目录 (Toc Scroll)**：横向滚动卡片式导读，提升长文阅读预期。
- **正文三层视觉**：
  - 锚点层：核心结论与深色引用块（全文 ≤ 5 处）。
  - 标记层：每个正文段落主动标记 1-3 个关键词下划线（使用主题指定 CSS）。
  - 容器层：概念标签、提示旁注与金句块。
- **作者签名区**：统一放于文章末尾，包含个人简介与三连互动引导。

### 1.1 深度长文结构模板（硬核拆解型 · 2026-08-07 样本沉淀）

行业现象 / 成本坍塌 / 门槛消失 / 热点爆款解剖类选题，按七段式写作：

1. **Hook（现象 + 反常识缺口）**：反差数字开局（30 元 vs 500 万播放），抛出全文问题（为什么偏偏是它？钱归谁？）。
2. **一、账本**：成本/价格结构，落到具体数字与来源。
3. **二、供给/渗透率**：证明不是个例。
4. **三、机制解剖（为什么是它）**：景观 vs 故事、看完率/分享率、生产与分发分离、审美/文化稀缺。
5. **四、稀缺品论证**：成本趋零 → 供给无限 → 注意力有限 → 流量与信任变贵，落到 3 个可操作稀缺项。
6. **五、行动判断**：给读者 3 条可执行判断。
7. **升华收尾**：判断力金句 + 留给读者的问题。

**反模式（退回重写）**：禁止独立「我的系统/自我实证」章节（个人工作流只作一句话案例）；结尾禁止仅复述前文数字；行业话题必须回答「为什么火/钱归谁」。

## 2. 视觉美学主导 (`xiaowan-wechat-layout-skill` No.1) 与 HTML 装配 (`gzh-design-skill` No.2)

以小晚美学 SOP (`xiaowan-wechat-layout-skill`) 为最高视觉规范，同时根据文章题材在 `gzh-design-skill/references/` 中自动匹配合适的主题组件库：

| 文章题材 | 推荐主题 | 组件库文件 | 特色 |
| :--- | :--- | :--- | :--- |
| **教程 / 清单 / 盘点 / 知识整理** | **摸鱼绿 (默认推荐)** | `theme-moyu-green.md` | Emerald 主色，卡片丰富、信息密度高 |
| **深度观点 / 品牌分析 / 力量感** | **红白色系** | `theme-red-white.md` | 正红点睛，编号章节与强金句卡 |
| **设计 / 科技评论 / 极简品牌** | **石墨极简风** | `theme-graphite-minimal.md` | 全灰阶，高冷理性 |

## 3. 合规检查、小晚移动端审核与一键交付

在装配 HTML 后，结合 `xiaowan-wechat-layout-skill` 执行移动端与合规确定性校验：

1. **首屏与无功能线条校验 (`@小晚不在` 规则)**：
   - 确保首屏仅包含刊头、主标题、识别资产、副标题与一句编者按，不堆叠标签墙与二重分隔线。
   - 标题下不重复画横线隔离正文，避免贯穿全文的极繁线条争抢视线。
   - 纠正第二行仅留 2-3 个汉字的孤行，语义完整处自然断行。
2. **内联样式与 `<span leaf="">` 检查**：确保粘贴进微信后台不丢失样式。
3. **标点规范**：正文使用全角标点，避免英文直引号。
4. **运行校验脚本**：
   ```bash
   python3 skills/gzh-design-skill/scripts/validate_gzh_html.py <HTML文件路径>
   ```
5. **生成带复制按钮的预览页**：
   ```bash
   python3 skills/gzh-design-skill/scripts/wrap_preview.py <HTML文件路径>
   ```

### 参考来源排版规范（论文式，强制）
- 文末「参考来源」统一使用**小号灰字**：标题 12px `#6B7280`，条目统一 11px（名称 `#6B7280`、说明 `#9CA3AF`），编号 `[1] [2] …`；
- **禁止红色背景药丸标签、禁止红色文字**；分隔线用浅灰 `#E5E7EB`；
- 每条格式 = 来源名称（含机构/日期）+ 关键数字说明，不裸链接；
- 该规范同步在 `workflows/产出标准.md`，质检复核时按此检查。

## 4. 最终输出格式

1. 多套公众号精选标题
2. 干净的正文 HTML 文件（`{文章名}_排版_{主题名}.html`）
3. 带有「复制到公众号」按钮的预览网页（`{文章名}_预览.html`）
