# 本周内容计划工作流 (Weekly Content Planning Workflow)

> **触发指令**：`本周内容计划` 或 `制定下周自媒体排期`  
> **核心原则**：个人 IP 阵地规划、热点与痛点结合、持续稳健输出

---

## 规划流程与输出结构

### 1. 内容赛道与比例划分
每周内容组合建议采用 **4:3:3 黄金比例**：
- **40% 核心干货 / 教程**：建立专业信任与高收藏量（如：“AI Codex 小白入门”、“超级排版指南”）。
- **30% 行业洞察 / 观点**：引发讨论与转发（如：“为什么传统编程门槛正在消失”）。
- **30% 个人 IP / 破局故事**：建立情感连接与陪伴感（如：“我是如何用 AI 搭建个人工作流的”）。
